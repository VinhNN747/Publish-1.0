# Super Tic-tac-toe 🎮
A browser-based Super Tic-tac-toe game built with **HTML, CSS, and JavaScript**.

## 🎯 Features
- 9x9 Super Tic-tac-toe logic
- Player vs Player mode
- Highlighted winning lines
- Responsive UI

## 🧠 Technologies
HTML, CSS, JavaScript (Vanilla)

## 🚀 How to Run
1. Clone this repo
2. Open `index.html` in your browser
3. Enjoy the game!
